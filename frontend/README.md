# Tạ Thanh Thiên — Personal Website & Portfolio

Personal website and developer portfolio built with Next.js 16, React 19, TailwindCSS v4, and TypeScript. Inspired by modern minimalist engineering portfolios (duyet.net).

🌐 **Live Demo / Preview**: [https://thienta2005.github.io/personal-website](https://github.com/ThienTa2005/personal-website)

---

## 🚀 Features

- **Minimalist Aesthetic & Typography**: Designed with Geist Sans and Geist Mono fonts.
- **Theme Mode**: Seamless Dark & Light mode toggle with persistent local storage and anti-flash script.
- **Interactive Selected Work**: Synced project showcase with custom `--work-tone` highlights, animated progress rails, and sticky visual cards.
- **Also Shipping**: Micro-project grid showcasing open-source tools and academic projects with colored letter badges.
- **Engineering Notes & Certifications**: Highlight cards for technical writing, achievements, and academic awards.
- **Curriculum Vitae (PDF)**: Integrated resume download and view directly at `/cv.pdf`.
- **AI / Agent Ready**: Includes `/llms.txt` and Schema.org JSON-LD structured data for web crawlers and AI agents.

---

## 🛠️ Tech Stack

- **Framework**: [Next.js 16](https://nextjs.org/) (App Router, Turbopack)
- **Library**: [React 19](https://react.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)

---

## 💻 Getting Started

Clone the repository and install dependencies:

```bash
git clone https://github.com/ThienTa2005/personal-website.git
cd personal-website
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 📦 Build for Production

```bash
npm run build
npm start
```
